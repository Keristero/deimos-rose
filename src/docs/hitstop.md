# Hitstop

`plugins/hitstop` (presentation only, off in classic mode, never in netplay).

- Every collision that hurts something is recorded by the core in `sim.Hit_Queue`
  (`sim/queue_hits.odin`, from `entity_hit` and `player_hit`). Like the other
  queues it is cleared each step and is not state or checksummed.
- The plugin's view turns each step's hits into a hold: `Renderer.hold` steps
  during which `flow_held` (game/flow.odin) skips the simulation step, so the
  simulation itself is untouched. The length is `round(1 + 3 * sqrt(damage))` steps
  (at least 1, at most 15), scaled by the HITSTOP setting.
- Any kill of an enemy by a player is a takedown and starts the kill cam: a
  post pass zooms the finished frame in on the unit (with letterbox bars) and
  draws the kill streak's name in the game font. It lasts 2.8 s of real time
  and slows the game rather than stopping it (`Renderer.slowdown`, which
  main.odin's accumulator takes off each frame, `flow_speed`): 30% speed for a
  light blow, down to 1% from 9 damage up (`slow_power`: `sqrt(damage) / 3`).
  The sound slows with it (`Textures.audio_slow` drops every sound's and the
  music's pitch, up to about half speed) and a reverb goes on the whole mix,
  both more for more damage (`view/reverb.odin`). The screen shakes hard as
  the blow lands (shake_power: `0.25 + 0.25 * sqrt(damage)`, all of it from 9
  damage up), and a deep boom, synthesised in `view/boom.odin`, plays.
- Kill streaks: each player's kills within 4 s of game time of the last go on
  their streak; its name is shown and spoken by an announcer (`view/announcer.odin`).
  Titles are `announcer/streaks.txt` (line N is streak N, 1 Takedown to 50);
  past 50 they come round again prefixed "Super", past 100 "Super Duper". The
  voice is Moonshine TTS, kokoro_am_michael, generated by `mise run
  hitstop:announcer` into `view/clips/` and embedded in the build, so nothing
  needs Moonshine to play. Edit the file and rerun the task to change a title.
- `mise run test` covers the numbers (`plugins/hitstop/tests`). For a look:
  `MENU=hitstop DR_HITSTOP_AT=0.5 mise run menu-shot` (the cam started by
  hand, 0 to 1 through it; DR_HITSTOP_STREAK=108 names a streak).
- Provisional: lengths, zoom and styling were picked by eye.
